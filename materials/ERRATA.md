# Known inaccuracies in the comments of the material files

The material files are generated by `scripts/make_material_variants.py`, and
every run records the SHA-256 of the file it was made from; the analysis admits
only runs whose recorded checksum matches the file on disk. Correcting a
comment would therefore retire every run made on that file, although no value
any simulation reads would change. The files are kept byte-identical to the
ones the runs used, and the comments that turned out to be wrong are corrected
here instead. None of them affects a number in the paper.

Recorded on 23 September 2026.

| File | As written | Correction |
|---|---|---|
| every file with the Gaussian emission band (the baseline and all variants except the two tabulated bands) | "no open source publishes it as a table -- src_B plots it in Fig. 8b but the underlying data sits behind an IEEE DataPort subscription, and the LBNL scintillator library lists the peak only" | Two numerical forms exist. SSLG4 (Comput. Phys. Commun. 306 (2025) 109385) distributes a 77-point table, attributed to a manufacturer; Fig. 2 of Mao, Zhang and Zhu, IEEE TNS 55 (2008) 2425 draws the measured photoluminescence band of the NaI(Tl) sample whose transmittance this study digitises. Both are run as variants (`NaI_Tl_meas_emission_sslg4.dat`, `NaI_Tl_meas_emission_mao.dat`). No measured scintillation spectrum with its conditions was located. |
| `NaI_Tl_abs_edge010.dat` | "Shallow edge: most transparent member of the scanned family." | E_U = 0.10 eV is the *steep* edge of the scan. It is the most transparent member. |
| `NaI_Tl_abs_edge025.dat` | "Steep edge: most absorbing member of the scanned family." | E_U = 0.25 eV is the *shallow* edge of the scan. It is the most absorbing member. |
| `NaI_Tl_meas_emission_sslg4.dat` | "The one openly distributed machine-readable NaI(Tl) emission band"; "the only openly distributed machine-readable band we located" | It is the only one distributed as a table. The photoluminescence band of Mao et al. (2008) Fig. 2 is a second numerical form, published as a figure and digitised here. |
| `NaI_Tl_abs_none.dat` | "1e7 mm, longer than any path a photon takes in a 76.2 mm crystal, so nothing is absorbed in bulk" | True of the runs with a lossy reflector, not of the lossless polished closure (G5), where photons can travel much further. The value is 1e7 mm (10 km); "no attenuation" means a length long compared with the paths photons take before they are detected or lost. |
| `NaI_Tl_abs_flat500.dat` | "The other value that appears in published Geant4 scintillator setups." | No published use of a flat 500 mm was located. The value is this study's own choice; the scanned edge brackets it and the flat 1000 mm that Feng et al., JINST 20 (2025) P02020, give LaBr3(Ce). |
| `NaI_Tl_rindex_flat185.dat`, `NaI_Tl_meas_rindex_flat185.dat` | "The single value quoted for NaI:Tl on essentially every manufacturer datasheet and in most simulation papers." | Unsupported as a count. In the sources this study read, a flat index is used by SSLG4 (1.85) and by Brown (2021, 1.86, read off a figure). |
| every file on the measured curve (`NaI_Tl_abs_measured*.dat`, `NaI_Tl_meas_*.dat`, 13 files) | "a single-beam transmittance does not separate absorption from scattering"; in `NaI_Tl_meas_scatter_max.dat` also "the absorption/scattering ambiguity a single-beam transmittance leaves" | The transmittance was measured with a double-beam spectrometer (Mao et al., Section III). Read "a transmittance measurement". |
